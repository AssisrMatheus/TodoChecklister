# TodoChecklister

A todo list for World of Warcraft. Write down the bosses to kill, the items to farm and the route to take, then tick them off.

![demoGif](./demo1.2.gif)

## Compatible with WoW Forever!!

TodoChecklister runs on WoW: Forever.

It also runs on Retail, Classic Era, TBC Anniversary and Mists of Pandaria Classic.

## Features

Open the window with the minimap button, a keybind (Esc > Options > Keybindings > AddOns) or `/todo tg`.

1. **Track items:** shift-click an item in your bags while typing to link it. The list shows how many you carry.
2. **Folders:** right-click an item to turn it into a folder, then drag items into it. Left-click a folder to rename it, and use its +/- button to open or close it.
3. **Reorder:** drag any item up or down the list.
4. **Quick add:** tick it at the top of the window and the text box stays open after Enter.
5. **Lists:** every character on your account sees your lists. Pick the one each character shows in Displayed list, under Esc > Options > AddOns > TodoChecklister.
6. **Share:** Export list, in the same options panel, gives you a code to send a friend. They paste it into Import list and get a copy, folders and checks included.

## Chat commands

| Command | What it does |
|---|---|
| `/todo help` | Lists the commands in chat |
| `/todo tg` | Opens or closes the window |
| `/todo reload` | Resets the window size, position and scale |
| `/todo add {text}` | Adds `{text}` to the list |
| `/todo rmv {position}` | Removes the item at `{position}` |
| `/todo mv {from} {to}` | Moves an item. `/todo mv 1 3` moves the first item to the third slot |
| `/todo chk {position}` | Checks or unchecks the item at `{position}` |
| `/todo lists` | Shows your saved lists, numbered |
| `/todo switch {position or name}` | Displays another list. `/todo switch 2` or `/todo switch Raid night` |
